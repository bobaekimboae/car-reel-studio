# 차량 숏폼 제작기

차량 정보와 사진으로 세로형 매물 소개 영상을 만드는 한국어 웹 도구입니다. 독립적으로 만든 서비스이며 AutoDash의 코드·브랜드·화면 자산을 포함하지 않습니다.

## 기능

- JPG, PNG, WebP 사진 최대 20장 추가
- 영상에 사용할 사진 최대 8장 선택, 순서 이동 및 삭제
- 차량 정보와 판매처 로고 입력
- 장면별 제목과 설명 편집, 3가지 영상 색상 테마
- 브라우저에서 9:16 영상 미리보기 및 다운로드
- 업로드한 사진과 정보는 브라우저 안에서만 처리

영상은 Canvas와 MediaRecorder로 브라우저에서 만듭니다. 지원 브라우저에서는 MP4, 그 외 브라우저에서는 WebM으로 저장됩니다. 생성 영상은 무음입니다. AI 차량 인식, 음성 해설, 배경 음악, 매물 사이트 URL 자동 가져오기는 포함하지 않습니다.

## 개발

```bash
npm ci
npm run dev
```

GitHub Pages 배포는 `main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`에서 자동 실행됩니다.
